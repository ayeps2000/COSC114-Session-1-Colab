## For students

1. Click **Open in Colab** for the session you need.
2. Sign in with your university or personal Google account if Colab asks you to.
3. Choose **File → Save a copy in Drive** before making changes.
4. Run a code cell with **Shift + Enter**, or **Ctrl + Enter** to run it and stay put.
5. When a cell asks for input, type your answer in the box below it and press **Enter**.

You do **not** need a GitHub account. GitHub is only hosting the class notebooks.

Avoid **Runtime → Run all** because some cells wait for keyboard input.

This repository contains the interactive COSC 114 Session 1 notebook.

## For students

1. Click **Open in Colab** above.
2. Sign in with your university or personal Google account if Colab asks you to.
3. Choose **File → Save a copy in Drive** before making changes.
4. Run a code cell with **Shift + Enter**.

You do **not** need a GitHub account. GitHub is only hosting the class notebook.

Avoid **Runtime → Run all** because some cells wait for keyboard input.
